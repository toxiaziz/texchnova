TECHNOVA — TEXNIKA DO‘KONI

Ishga tushirish:
1. ZIP faylni chiqarib oling.
2. texno_market papkasini oching.
3. index.html faylini Chrome yoki boshqa brauzerda oching.

Fayllar:
- index.html — sahifa tuzilishi
- style.css — dizayn va moslashuvchan (responsive) ko‘rinish
- script.js — mahsulotlar, qidiruv, filtrlar, sevimlilar va savat funksiyalari

Eslatma:
Bu front-end demo loyiha. Mahsulotlar namunaviy, narxlar o‘zgartirilishi mumkin.
Haqiqiy buyurtma, onlayn to‘lov, ombor va admin panel uchun backend hamda to‘lov/yetkazib berish integratsiyasi kerak.
